# ios-app-template

iOS アプリの初期テンプレート。SwiftUI の 1 画面のみを含む最小構成。

## 環境

| 項目 | バージョン |
| --- | --- |
| Xcode | 26.x |
| Swift | 5.0 |
| Deployment Target | iOS 26.5 |

## ビルド

`ios-app-template.xcodeproj` を Xcode で開いて実行する。
